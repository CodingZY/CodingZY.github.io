## 📌 题目

> 给你一个字符串 s 和一个字符串列表 wordDict 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 s 则返回 true。注意：不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

## 💡 思路
- dp[n+1] 长度
- j 切点，也是后面串的起点坐标
- set作为wordDict的o(1)查找


## 💻 代码

```cpp
bool wordBreak(string s, vector<string>& wordDict) {
    unordered_set<string> wordSet(wordDict.begin(),wordDict.end());
    int n=s.size();
    vector<bool> dp(n+1,false); //表示长度
    dp[0]=true;
    for(int i=1;i<=n;i++){
        for(int j=0;j<i;j++){ //表示切点前的长度，也表示切点的坐标
            if(dp[j]&&wordSet.count(s.substr(j,(i-1-j +1)))) dp[i]=dp[j];
        }
    }
    return dp[n];
}
```
