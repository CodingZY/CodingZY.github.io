## 📌 题目

> 给你两个字符串 s 和 t ，统计并返回在 s 的 子序列 中 t 出现的个数。测试用例保证结果在 32 位有符号整数范围内。

## 💡 思路
- 套路：s[i-1]==t[j-1] 状态转移方程：dp[i][j]=用i+不用i=i-1 else  没得i用=i-1  j永远都是j


## 💻 代码

```cpp
int numDistinct(string s, string t) {
    int n1=s.size(),n2=t.size();
    vector<vector<unsigned long long>> dp(n1+1,vector<unsigned long long>(n2+1,0));
    for(int i=0;i<=n1;i++) dp[i][0]=1;
    for(int i=1;i<=n1;i++){
        for(int j=1;j<=n2;j++){
            if(s[i-1]==t[j-1]) dp[i][j]=dp[i-1][j-1]+dp[i-1][j];
            else dp[i][j]=dp[i-1][j];
        }
    }
    return dp[n1][n2];
}
```
