## 📌 题目

> 给你一个整数数组 nums，有一个大小为 k 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 k 个数字。滑动窗口每次只向右移动一位。返回 滑动窗口中的最大值 。

## 💡 思路
- index大且数值大的，前面数值存起来就没意义了
- 前面初始化队列已经用了一次滑动窗口，所以后面的遍历带nums.size()-1就行了
- push_back()、pop_back()尾弹、front()队头、pop_front()头弹


## 💻 代码

```cpp
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    int left=0,right=k-1;
    deque<int> q;
    q.push_back(nums[0]);
    //初始化双向队列
    for(int i=1;i<k;i++){
        while(!q.empty()&&q.back()<nums[i]){
            q.pop_back();
        }
        q.push_back(nums[i]);
    }

    vector<int> res;
    res.push_back(q.front());
    while(right+1<nums.size()){
        if(nums[left]==q.front()){
            q.pop_front();
        }
        left++;
        right++; //right=nums.size()数组越界
        while(!q.empty()&&q.back()<nums[right]){
            q.pop_back();
        }
        q.push_back(nums[right]);
        res.push_back(q.front());
    }
    return res;
}
```
