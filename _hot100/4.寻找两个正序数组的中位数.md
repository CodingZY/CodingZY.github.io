## 📌 题目

> 给定两个大小分别为 m 和 n 的正序（从小到大）数组 nums1 和 nums2。请你找出并返回这两个正序数组的 中位数 。算法的时间复杂度应该为 O(log (m+n)) 。

## 💡 思路

- 在 nums1 中切一刀，位置记为 i（代表 nums1 左边有 i 个元素）；在 nums2 中切一刀，位置记为 j。为了让左右两边元素个数相等（或左边多一个），j 的位置是固定的 (m+n+1)/2-i;
- 切完后，两个数组会被分为：nums1 左边最大值 maxLeft1，右边最小值 minRight1nums2 左边最大值 maxLeft2，右边最小值 minRight2当且仅当满足以下两个交叉条件时，说明切分正确：nums1 左边 <= nums2 右边 && nums2 左边 <= nums1 右边

## 💻 代码

```cpp
double findMedianSortedArrays(vector<int>& nums1, vector<int>& nums2) {
    // 二分查找的前提是 nums1 是较短的数组（即 $m \le n$）。如果你传进来的 nums1 比 nums2 长，j 的计算可能会超出 nums2 的范围（小于 0 或大于 n）
    // 保证 nums1 是较短的数组，如果不是则交换
    if (nums1.size() > nums2.size()) {
        return findMedianSortedArrays(nums2, nums1);
    }
    int m=nums1.size();
    int n=nums2.size();
    int mid=(m+n+1)/2; //奇数时让左边多一个数
    int low=0,high=m; //以num1的一半为起始
    while(low<=high){
        // 切点为i：[0,i-1]
        int i=(low+high)/2;
        int j=mid-i;
        int left_max1=(i==0)?INT_MIN:nums1[i-1];
        int right_min1=(i==m)?INT_MAX:nums1[i];

        int left_max2=(j==0)?INT_MIN:nums2[j-1];
        int right_min2=(j==n)?INT_MAX:nums2[j];

        if(left_max1<=right_min2&&left_max2<=right_min1){
            // 找到了正确切分的位置
            if((m+n)%2==1){
                //总长度为奇数,中位数为左半部分最大值
                return max(left_max1,left_max2);
            }
            else return (max(left_max1,left_max2)+min(right_min1,right_min2))/2.0;
        }
        else if(left_max1>right_min2) high=i-1;
        else low=i+1;

    }
    return 0.0;
}
```
