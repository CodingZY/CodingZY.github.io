## 📌 题目

> 给定两个字符串 s 和 t，长度分别是 m 和 n，返回 s 中的 最短窗口 子串，使得该子串包含 t 中的每一个字符（包括重复字符）。如果没有这样的子串，返回空字符串 ""。

## 💡 思路
- window_map,t_map,valid_count
- valid_count的计算就在right每次+1时，如果window_map[s[right]] == t_map[s[right]],valid_count++
- 右移到一个有效字符后，轮到左移
- 左移只有在valid_count==t_map.size()才进行。判断min_len，但要左移的为有效字符且window_map[s[left]] == t_map[s[left]]时，valid_count--

    unordered_map<char,int> t_map;
    unordered_map<char,int> window_map;
    // unordered_map<char,bool> vis_map;
    for(int i=0;i<t.size();i++){
        t_map[t[i]]++;
        // vis_map[t[i]]=true;
    }
    // 初始化队列
    int valid_count=0;
    int left=0,right=0;
    string res="";
    int min_len=INT_MAX,start_index=0;
    //不要初始化队列,直接一次边界结束找到满足的答案就行
    while(right<s.size()){
        if(t_map.count(s[right])){
            window_map[s[right]]++;
            if(window_map[s[right]] == t_map[s[right]]) valid_count++;
        }
        right++;

        // 当窗口涵盖了 t 中所有字符时，尝试收缩左边界 left 寻找最短窗口
        while(valid_count==t_map.size()){
            if(right-left<min_len){
                // 频繁调用 s.substr() 会爆
                // res=s.substr(left,right-left);
                start_index=left;
                min_len=right-left;
            }
            
            if(t_map.count(s[left])){
                if(window_map[s[left]] == t_map[s[left]]) valid_count--;
                window_map[s[left]]--;
            }
            left++;

        }

    }
    // while(right<s.size()||valid_count==t_map.size()){

    // else return res;

    // while(right<s.size()){
    //     while(t_map.count(s[left])!=0){
    //         left++;
    //     }
    //     if(window_map[s[left]]==t_map[s[left]]){
    //         valid_count--;
    //     } 
    //     left++;

    //     while(t_map.count(s[right])!=0){

    //     if(window_map[s[right]]==t_map[s[right]]){

    if(min_len!=INT_MAX) return s.substr(start_index,min_len);

}
