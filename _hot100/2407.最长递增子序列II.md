## 📌 题目

> 给你一个整数数组 nums 和一个整数 k 。
找到 nums 中满足以下要求的最长子序列：
子序列 严格递增
子序列中相邻元素的差值 不超过 k 。
请你返回满足上述要求的 最长子序列 的长度。

子序列 是从一个数组中删除部分元素后，剩余元素不改变顺序得到的数组。

## 💡 思路
- for(int j=0;j<i;j++)会爆 1 <= nums.length <= 10^5  O(n^2)=10^10-> 优化为从[nums[i] - k, nums[i] - 1]找最大->用树结构
- modify叶子阶段赋值=递归出口，递归左/右子树，max_val[o]=max(max_val[o*2],max_val[o*2+1])向上合并回传最大值
- 查找某个范围的dp最大值O(logN).存在L R范围不包含的数则递归查询直到包含
- 树的节点值不是下标，是nums[i]


## 💻 代码

```cpp
vector<int> max_val;
void modify(int o,int l,int r,int i,int val){
    //o节点下标 l r数值范围 i要修改的数值 dp的值val
    if(l==r){ //叶子节点，走到叶子节点就是到了i
        max_val[o]=val;
        return;
    }
    int m=(l+r)/2;
    if(i<=m) modify(o*2,l,m,i,val); //递归左树
    else modify(o*2+1,m+1,r,i,val); //递归右树
    max_val[o]=max(max_val[o*2],max_val[o*2+1]); //向上合并回传最大值
}
int query(int o,int l,int r,int L,int R){
    // 查询的范围L R
    if(L<=l&&r<=R) return max_val[o];
    int res=0;
    int m = (l + r) / 2;
    //存在L R范围不包含的数则递归查询直到包含
    if (L <= m) res = query(o * 2, l, m, L, R);
    if (R > m) res = max(res, query(o * 2 + 1, m + 1, r, L, R));
    return res;
}
int lengthOfLIS(vector<int>& nums, int k) {
    // int n=nums.size();
    // vector<int> dp(n,0); //下标为i的最长子序列
    // dp[0]=1;
    // for(int i=1;i<n;i++){
    //     dp[i]=1;
    //     for(int j=0;j<i;j++){ //优化为[nums[i] - k, nums[i] - 1]
    //         if(nums[i]>nums[j]&&nums[i]-nums[j]<=k){
    //             dp[i]=max(dp[i],dp[j]+1);
    //         }
    //     }
    // }
    // return *max_element(dp.begin(),dp.end());

    // 线段树
    int u = *max_element(nums.begin(), nums.end());
    max_val.resize(u * 4);
    for (int x: nums) {
        if (x == 1) modify(1, 1, u, 1, 1);
        else {
            int res = 1 + query(1, 1, u, max(x - k, 1), x - 1);
            modify(1, 1, u, x, res);
        }
    }
    //父节点,即遍历完的最大递增子序列
    return max_val[1];
}
```
