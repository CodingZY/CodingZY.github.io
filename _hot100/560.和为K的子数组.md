## 📌 题目

> 给你一个整数数组 nums 和一个整数 k ，请你统计并返回 该数组中和为 k 的子数组的个数 。子数组是数组中元素的连续非空序列

## 💡 思路
- 注意遍历时不能使用未来的前缀和


## 💻 代码

```cpp
int subarraySum(vector<int>& nums, int k) {
    int res=0;
    unordered_map<int,int> psum;
    psum[0]=1;
    int tmp=0;
    // for(int i=0;i<nums.size();i++){
    //     tmp+=nums[i];
    //     psum[tmp]++;
    // }
    // tmp=0;
    // for(int i=0;i<nums.size();i++){
    //     tmp+=nums[i];
    //     // 使用了未来的前缀和
    //     res+=psum[tmp-k];
    // }
    for(int i=0;i<nums.size();i++){
        tmp+=nums[i];
        res+=psum[tmp-k];
        psum[tmp]++;//计算到当前时，当前还没有成为过去的前缀和
    }
    return res;
}
```
