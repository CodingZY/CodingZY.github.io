## 📌 题目

> 给你一个字符串 s，请你将 s 分割成一些子串，使每个子串都是回文串。返回符合要求的 最少分割次数 。

## 💡 思路
- dp[n+1] 长度
- j 切点，也是后面串的起点坐标
- 回文串判定查询 dp[i][j]


## 💻 代码

```cpp
int minCut(string s) {
    int n=s.size();
    // 先二维dp把回文情况记录下来
    vector<vector<bool>> isPal(n,vector<bool>(n,false));
    for(int i=0;i<n;i++) isPal[i][i]=true;
    for(int len=2;len<=n;len++){
        for(int i=0;i<n;i++){
            int j=len+i-1;
            if(j>=n) break;
            if(s[i]==s[j]){
                if(len==2) isPal[i][j]=true;
                else isPal[i][j]=isPal[i+1][j-1];
            }
        }
    }
    // 再用一维dp遍历分割点
    vector<int> dp(n+1);
    for(int i=1;i<=n;i++){ //长度
        if(isPal[0][i-1]){
            dp[i]=0;
            continue;
        }
        dp[i]=i; //最坏的情况
        for(int j=0;j<i;j++){ //j是切点，也是后半段起点的坐标
            // 只有当后半段 s[j...i-1] 是回文串时，才考虑
            if(isPal[j][i-1]){
                dp[i]=min(dp[i],dp[j]+1);
            }
        }
    }
    return dp[n];
}
```
