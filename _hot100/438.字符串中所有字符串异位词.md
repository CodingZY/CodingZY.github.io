## 📌 题目

> 给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 **异位词** 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

## 💡 思路

- 异位词 → **滑动窗口（固定窗口大小）**
- `unordered_map<char, int>` 要初始化为 26 个英文字母，`int = 0`
- 也可以用 `vector<int> window(26, 0)`，访问 `window[s[i] - 'a']`

## 💻 代码

```cpp
vector<int> findAnagrams(string s, string p) {
    vector<int> res;
    if (s.size() < p.size()) return res;
    unordered_map<char, int> truth;
    unordered_map<char, int> window;
    for (int i = 0; i < 26; i++) {
        truth['a' + i] = 0;
        window['a' + i] = 0;
    }
    int left = 0, right = p.size() - 1;
    // 初始化窗口
    for (int i = 0; i < p.size(); i++) {
        truth[p[i]]++;
        window[s[i]]++;
    }
    if (window == truth) res.push_back(left);
    while (right < s.size()) {
        window[s[left]]--;
        left++;
        right++;
        window[s[right]]++;
        if (window == truth) res.push_back(left);
    }
    return res;
}
```
